# Salary Analytics Dashboard (Excel)

An interactive HR salary dashboard built in Excel using Pivot Tables, Pivot Charts and Slicers.

## Preview
![Salary Analytics Dashboard](Salary_Analytics_Dashboard.png)

## What the dashboard shows
- Salary share by gender, city and department
- Employee count by department and city
- Employee count by role within each department
- Employee trend by years of experience
- Job Role slicer to filter the whole dashboard

## Workbook structure (`Employee_Dashboard_Data.xlsx`)
| Sheet | Purpose |
|---|---|
| Raw_Data | 520 employee records: EmployeeID, Name, Department, Experience_Years, Education_Level, Age, Gender, City, Monthly_Salary, JobRole |
| Reports | Pivot tables that feed the charts |
| Dashboard | Final dashboard with charts and slicer |

## Tools used
Advanced Excel: Pivot Tables, Pivot Charts, Slicers
